## ✨ Overview

The **Contractor Worker Management System** is a full-stack MERN application designed to simplify contractor operations by managing workers, attendance, salaries, project sites, and reports from a single dashboard.

---

## 🚀 Features

### 👷 Worker Management
- Add, Edit & Delete Workers
- Worker Profiles
- Skills & Work Type
- Contact Information
- Joining Date

### 📅 Attendance
- Daily Attendance
- Site-wise Attendance
- Attendance History
- Monthly Reports

### 💰 Salary Management
- Automatic Wage Calculation
- Advance Payments
- Payment History
- Remaining Balance

### 🏗️ Site Management
- Multiple Projects
- Assign Workers
- Site-wise Tracking

### 📊 Dashboard
- Total Workers
- Today's Attendance
- Total Wages
- Paid & Pending Payments

### 📄 Reports
- Attendance Reports
- Salary Reports
- Monthly Expenses
- PDF & Excel Export

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/contractor-worker-management.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
